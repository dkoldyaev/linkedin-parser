Legacy API не трогаем оставляем как есть. В документации его быть не должно. Внешний доступ заблокирован независимо от feature-flag api_access

------------

Оставляем с доступом по API_KEY
Внешний доступ разрешен только при включенном feature-flag api_access. Отображается в документации:

* `/api/v1/*`

------------

Оставляем только для frontend (удаляем доступ по API_KEY) и удаляем из документации. Внешний доступ заблокирован независимо от feature-flag api_access

* `/api/v2/auth`
* `/api/v2/feature-flags`
* `/api/v2/users`
* `/api/v2/admin`
* `/api/v2/config`
* `/api/v2/settings`
* `/api/v2/api-keys`
* `/api/v2/vacancies/{vacancy_id}/adapt-cv`

------------

Удаляем из документации оставляем только для расширения. Внешний доступ заблокирован независимо от feature-flag api_access

* `/api/v2/extension`

------------

Делаем (оставляем) публичными с доступом по API_KEY
Внешний доступ разрешен только при включенном feature-flag api_access. Отображается в документации

* `/api/v2/exchange-rates`
* `/api/v2/vacancies/`
* `/api/v2/vacancies/*`
* `/api/v2/columns`
* `/api/v2/columns/*`
* `/api/v2/queue/*`
* `/api/v2/cv/anonymize-companies`
* `/api/v2/cv`
* `/api/v2/stats`
* `/api/v2/tags`
* `/api/v2/countries`
* `/api/v2/cities`
* `/api/v2/sources`

------------

Нужно больше подробностей

* `/api/v2/config` какие еще настройки LLM провайдеров, Mercure SSE URL и т.д. Что именно он настраивает и где я это вижу?
* `/api/v2/settings` Откуда это вообще? Какие именно ключи?
* `/api/v2/queue/tasks/{task_id}` Где именно это используется? Нужно убедиться что пользователь не имеет доступа к чужим задачам
* `/api/v2/queue/links/{task_id}` Наверное здесь должно быть `link_id`
* `/api/v2/cv/approved` POST/DELETE лишние. Должны работать. Функционал POST/DELETE необходимо перенести в `/api/v2/cv`.
* `/api/v2/vacancies/{vacancy_id}/compatibility` Это лишнее. Необходимо сделать так: при GET /api/v2/vacancies я получаю только данные необходимые для отображения карточек. При запросе `/api/v2/vacancies/{vacancy_id}` я получаю все данные для отображениы открытой карточки. Вместе с compatibility чтобы при открытии не делать два запроса одновременнно
